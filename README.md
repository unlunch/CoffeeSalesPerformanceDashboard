# ☕ Coffee Sales Performance Dashboard
📊 Analisis Penjualan Kopi Menggunakan Excel
## 🔍 Overview
Coffee Sales Performance Dashboard adalah proyek analisis data yang dibuat menggunakan Excel, yang bertujuan untuk memberikan insight terhadap tren penjualan kopi berdasarkan dataset yang tersedia.

Dashboard ini menampilkan penjualan bulanan, produk terlaris, performa toko, dan analisis pelanggan dengan visualisasi yang interaktif.

## 🚀 Fitur
### ✅ Data Cleaning & Preparation
- Menggunakan Remove Duplicates untuk membersihkan data duplikat.
- Menerapkan IF Function untuk validasi dan pengolahan data.
### ✅ Data Processing & Lookup
- XLOOKUP & INDEX-MATCH untuk pencarian data pelanggan dan transaksi secara efisien. 
### ✅ Data Visualization
- Pivot Table & Pivot Chart untuk membuat laporan interaktif.
- Conditional Formatting untuk menyoroti tren penting.
### ✅ Dashboard Building
- Menggunakan slicing dan filtering untuk analisis yang lebih fleksibel.
- Desain yang rapi dan mudah dipahami untuk mendukung pengambilan keputusan bisnis.

## 📂 Dataset
- Kaggle : https://www.kaggle.com/datasets/mohammadkaiftahir/coffee-orders-data

## 🛠️ Tools & Technologies
- Excel (Pivot Table, Pivot Chart, XLOOKUP, INDEX-MATCH, IF Function, Formatting, Dashboard Design)
